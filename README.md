# Capstone Project — Pima Indians Diabetes Risk Prediction

Final capstone for the AnalystLab Africa Machine Learning Internship.
Builds on the Week 7 deployment ( [https://github.com/Ibinabo-Direh/Week-7-Diabetes-Prediction-API-Deployment] ) with deeper EDA, 
full problem framing, and a complete project report.

## Contents
- `Capstone Project - Pima Indians Diabetes.ipynb` — full notebook (EDA, model, evaluation)
- `Week 8 Analyst Lab Report.docx` — written report
- `diabetes_api.py` — FastAPI deployment
- `diabetes_model.pkl`, `diabetes_scaler.pkl` — saved model/scaler
- `diabetes.csv` — dataset
- `Screenshots/` — supporting evidence

## How to Run
See API_DOCS or the "How to Run the API" section in the report — same 
setup as Week 7 (create venv, `pip install fastapi uvicorn joblib scikit-learn`, 
`uvicorn diabetes_api:app --reload`).
